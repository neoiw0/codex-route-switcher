第一步，微软商店下 ChatGPT（Codex 桌面版），启动一次直接退出，在任务栏完全退出。

第二步（第一次用才需要），弄一个 API Key：
- 用 OpenCode（推荐，便宜）：注册 GitHub 账号（打开 https://github.com/signup ，用邮箱注册，再去邮箱点验证链接；GitHub 没有中文版，浏览器右键可以翻译）。然后打开 https://opencode.ai ，点 Sign in with GitHub 登录，授权后在控制台创建 API Key（API Keys → Create），复制以 sk- 开头的密钥。
- 用 DeepSeek 官方：打开 https://platform.deepseek.com 注册登录，在 API Keys 里创建一个 Key（sk- 开头）。
- 用 Fox：在 Fox 平台注册并创建 Key。

第三步，双击 bat 文件：
- 输入 1 回车 = 用 OpenCode Go（推荐，默认），然后选模型（比如 DeepSeek Flash）；
- 输入 2 回车 = 用 DeepSeek 官方 API，然后选模型（deepseek-v4-flash 或 deepseek-v4-pro-0813）；
- 输入 3 回车 = 用 Fox（可选）。
- 第一次用会让你输密钥（粘贴密钥：ctrl+v 不行的话就鼠标右键）。

新版会自动完全退出旧的 Codex/ChatGPT、切换好路由后再重新启动，期间不用手动关（耐心等它跑完提示）。

每次切换时，选好模型后，脚本会自动把所有旧聊天也同步成你选的这个模型，不用单独操作。
思考强度不用在切换器里选：切换器会按模型自动设置好可用档位，打开 Codex 后，在聊天窗口里自己调即可。

第四步，打开 Codex，最好创建一个项目文件夹，需要处理的东西都放进文件夹里。

如果聊天记录打不开/不见了：双击 bat 输入 5（修复历史聊天供应商），会自动关闭 Codex、把所有旧聊天的供应商改成 CC（只改名字，聊天模型不变），然后重新打开 Codex，聊天记录就回来了。

如果新开的聊天窗口第一条消息报 "Invalid schema for function 'automation_update'"：
- 说明上次切换后旧进程没有完全退出；先把 Codex 完全退出（任务栏右键-退出），再双击 bat 重新切换一次，然后开【新的】聊天窗口；
- 或者先直接复用已经正常的旧聊天窗口。

如果新开的聊天窗口第一条消息报 "tools...missing field name"（切到 Pro、GLM、Kimi 等模型时）：
- 这是 OpenCode 网关不认搜索工具导致的，不是你弄错了；重新双击 bat、重新选一次你想要的模型（新版会自动处理好），然后开【新的】聊天窗口即可。

OpenCode 里目前只有 4 个模型能用：DeepSeek Flash、Hy3、Kimi K2.5、Kimi K2.6（菜单里只显示这些）。
想用 Pro（deepseek-v4-pro-0813）：选第 2 项"DeepSeek 官方 API"，需要先去 https://platform.deepseek.com 注册并创建 API Key（sk- 开头）。
